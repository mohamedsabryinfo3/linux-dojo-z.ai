# 🥋 LinuxDojo — أكاديمية لينكس التفاعلية بالعربية

موقع تعليمي تفاعلي كامل لإتقان لينكس من الصفر حتى مستوى مهندس الأمن السيبراني (SOC) — **ملف HTML واحد، بلا خادم، بلا تبعيات، بلا خطوات بناء.**

> 🌐 يعمل مباشرة بفتح `index.html` في أي متصفح — أو انشره على Vercel/GitHub Pages بضغطة واحدة.

---

## ✨ المزايا

| الميزة | التفاصيل |
|---|---|
| 📚 **23 درسًا احترافيًا** | 5 وحدات متدرجة: الأساسيات ← إدارة النظام ← الشبكات ← الأمن و SOC ← Bash والأتمتة |
| 🎨 **23 مخططًا تفاعليًا (SVG)** | لكل مفهوم وعلاقة: طبقات النظام، شجرة FHS، الصلاحيات، systemd، SSH، SELinux، الأنابيب... |
| 📖 **قصة تفتتح كل درس** | من قصة لينوس تورفالدس إلى سيناريوهات هجوم حية — المفهوم يُبنى بالقصة لا بالحفظ |
| 🎮 **محاكي طرفية تفاعلي** | نظام ملفات افتراضي حي: `ls`, `cd`, `grep`, `systemctl`, `journalctl`... مع سجلات اختراق تحقق فيها كمحلل SOC |
| 🐧🎩 **مفتاح Debian ↔ Rocky** | شرح موحّد، والفروق (apt/dnf) في صناديق تبديل فورية |
| 🛡️ **زاوية SOC في كل درس** | كيف يستغل المهاجم المفهوم وكيف تصطده |
| 📝 **اختبار تفاعلي (69 سؤالًا)** | 3 أسئلة بعد كل درس مع تفسير فوري |
| ✅ **تتبع التقدم** | محفوظ في متصفحك (localStorage) مع بديل آمن في الذاكرة |
| 📱 **متجاوب بالكامل** | من 375px موبايل حتى شاشات سطح المكتب — RTL عربي كامل |

## 🚀 التشغيل محليًا

```bash
# لا حاجة لأي تثبيت — فقط افتح الملف:
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

أو شغّل خادمًا محليًا بسيطًا (اختياري):

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## ☁️ النشر على Vercel

**الطريقة 1 — من Git (موصى بها):**
1. ارفع هذا المجلد لمستودع GitHub
2. اذهب إلى [vercel.com/new](https://vercel.com/new) واستورد المستودع
3. Vercel سيكتشف تلقائيًا موقعًا ثابتًا — اضغط **Deploy** (لا إعدادات مطلوبة)

**الطريقة 2 — سطر الأوامر:**
```bash
npm i -g vercel
vercel          # من داخل هذا المجلد — سينشر index.html مباشرة
```

## ☁️ النشر على GitHub Pages

1. ارفع المجلد لمستودع GitHub
2. Settings ← Pages ← Source: `main` branch / root
3. سيصبح الموقع متاحًا على `https://<username>.github.io/<repo>`
